# Investigation of Event Correlation Issues in New Dataset

**Issue**: Survival curves show proper CHADS-VASc risk stratification in old dataset but complete failure in new dataset

## Summary

Through systematic investigation, we discovered that the new dataset (`random_nuchad_250623.csv`) has **fundamental data integrity problems** that prevent proper clinical risk stratification. Despite identical stroke event counts, the new dataset lacks basic epidemiological relationships between age, CHADS-VASc scores, and stroke outcomes.

## Background: The Original Problem

**Observation**: Survival curves generated by `uv run run_survival_eda` showed:
- **Old dataset**: Clear separation by CHADS-VASc risk groups (10-year survival: ~0.90, 0.81, 0.71)
- **New dataset**: No separation (10-year survival: ~0.82, 0.81, 0.81)

**Initial hypothesis**: Different stroke encoding between datasets was causing event misclassification.

## Investigation Timeline

### 1. Initial Analysis: `analyze_survival_curve_separation.py`
**Goal**: Replicate the survival numbers and confirm the issue  
**Results**: 
- ✅ Successfully replicated the reported 10-year survival numbers
- ✅ Confirmed complete lack of curve separation in new dataset
- ❌ Original survival analysis approach could not explain the issue

### 2. Stroke Encoding Analysis: `analyze_stroke_encoding.py` (Pre-existing)
**Key Discovery**: Fundamental stroke encoding incompatibility:

| Dataset | stroke_1Y = 1 | stroke_1Y = 2 | Missing |
|---------|---------------|---------------|---------|
| **Old** | Stroke within 1Y | **NO STROKE** (controls) | N/A |
| **New** | Stroke within 1Y | **Stroke AFTER 1Y** | **NO STROKE** (controls) |

**Critical incompatibility**: `stroke_1Y = 2` has **opposite meanings** between datasets.

### 3. Enhanced Survival Classification: `src/nuchad/analysis/survival_v2.py`
**Goal**: Create dataset-aware classification system  
**Components**:
- `classify_events_and_controls()`: Dataset-specific stroke encoding logic
- `classify_censoring()`: Explicit censoring classification  
- `prepare_survival_data_v3()`: Integrated survival preparation with validation

**Test Results**: `test_survival_v2.py`
- ✅ Old dataset: Maintained proper risk stratification 
- ❌ New dataset: Still no risk stratification despite corrected encoding

### 4. Simple Event Definition Testing: `test_event_definitions.py`
**Goal**: Test if basic event definitions show age correlation  
**Method**: Ignore stroke_1Y, use only stroke dates and timing

**Tested Definitions**:
1. `stroke_1Y = 1` (original approach)
2. Has stroke date (regardless of stroke_1Y)
3. `stroke_1Y = 1` AND has stroke date  
4. Stroke date after time1
5. Stroke within 1 year of AF diagnosis
6. Various time windows and exclusions

**Results**: 
- **Old dataset**: ALL definitions work (r = 0.055-0.093, gradients = 3.4-12.2%)
- **New dataset**: ALL definitions fail (r ≈ 0, gradients < 0.5%)

### 5. Date-Based Event Analysis: `test_date_based_events.py`
**Goal**: Use dataset creator's guidance to focus on temporal relationships  
**Dataset Creator Insights**:
- "Ignore stroke_1Y completely, use actual dates"
- "Day-of-diagnosis strokes might be coding artifacts"
- "Exclude patients with prior strokes"

**Key Discovery**: **Temporal ordering problems in new dataset**
- 33.7% of strokes occur **BEFORE** AF diagnosis
- 21.6% occur on **same day** (coding artifacts)
- Median stroke time: **0 days** (vs 235.5 days in old dataset)

**Result**: Even with clean temporal definitions, **no risk stratification recovered**.

### 6. Stroke_1Y Value Combinations: `test_stroke_1y_combinations.py`
**Goal**: Systematically test all stroke_1Y value combinations based on encoding analysis

**Interpretations from `analyze_stroke_encoding.py`**:
- stroke_1Y = 1.0: Stroke within 1 year of AF diagnosis  
- stroke_1Y = 2.0: Stroke AFTER 1 year of AF diagnosis
- stroke_1Y = 3.0: Stroke same day as AF diagnosis
- stroke_1Y = 4.0: Stroke BEFORE AF diagnosis
- Missing: Controls (no stroke)

**Tested 9+ combinations per dataset including**:
- Individual values ([1], [2], [3], [4])
- Logical combinations ([1,3], [1,2], [1,2,3], [1,2,3,4])
- Controls (Missing values)

**Results**: **COMPLETE FAILURE** across all combinations in new dataset
- Age correlations: r ≈ 0.000 ± 0.006 (all non-significant)
- Risk gradients: 0.0-0.5% (no stratification)
- **Even stroke_1Y = 2 (stroke after 1Y) shows no risk gradient**

### 7. Treatment Stratification: `test_treatment_stratified.py`
**Goal**: Test if treatment regime differences explain the correlation failure  
**Hypothesis**: Different treatment patterns might confound risk relationships

**Treatment Distributions**:
- **Old dataset**: 100% on OAC (homogeneous)
- **New dataset**: 
  - 46.0% treatment outside window
  - 39.7% no treatment  
  - 8.0% antiplatelet only
  - 5.1% OAC only
  - 1.2% both treatments

**Results**: **HYPOTHESIS REJECTED**
- Even within identical treatment strata, new dataset shows no age/CHADS-VASc correlation
- **Within no-treatment group**: r = -0.005, gradient = 0.2%
- **Within OAC-only group**: r = 0.026, gradient = 0.9%
- **All treatment strata fail** to show meaningful risk stratification

## Data Quality Issues Identified

### 1. Temporal Ordering Problems
- **33.7% of strokes occur before AF diagnosis** (should be 0%)
- **Median stroke time = 0 days** (should be >200 days)
- **Same-day stroke artifacts** (21.6% in new vs old dataset patterns)

### 2. Loss of Clinical Relationships  
- **Age does not correlate with stroke risk** (r ≈ 0 vs r = 0.055-0.093)
- **CHADS-VASc scores do not predict outcomes** (0.0-0.5% gradient vs 3.4-12.2%)
- **Risk factors show no association with events**

### 3. Encoding Inconsistencies
- **Identical event counts but different distributions** across risk groups
- **Stroke timing patterns are non-physiological**  
- **Treatment patterns suggest different populations**

## Conclusions

### Primary Conclusion
**The new dataset has irreparable data integrity issues** that prevent meaningful clinical risk analysis. The lack of survival curve separation is a symptom of fundamentally broken epidemiological relationships.

### Specific Issues Cannot Be Resolved By:
- ❌ Different event definitions
- ❌ Stroke encoding corrections  
- ❌ Temporal window adjustments
- ❌ Treatment stratification
- ❌ Patient filtering approaches

### Root Cause Assessment
The new dataset appears to have one or more of:
1. **Scrambled/mismatched patient records** where risk factors don't match outcomes
2. **Systematic data corruption** that broke clinical relationships  
3. **Synthetic/artificial data** that lacks real epidemiological patterns
4. **Fundamental population differences** that invalidate comparisons

### Recommendations

1. **Investigate data provenance**: How was the new dataset created/processed?
2. **Validate source records**: Check a sample of patients against original clinical records
3. **Consider data reconstruction**: May need to rebuild from source if possible
4. **Use old dataset for analysis**: Continue with proven dataset until new data is validated
5. **Alert collaborators**: Share findings about data integrity issues

### Impact on Research
- **Survival analysis results**: Only old dataset provides reliable results
- **Transportability analysis**: Cannot perform valid cross-dataset comparisons  
- **Model validation**: New dataset cannot serve as validation cohort
- **Clinical conclusions**: Any findings from new dataset are questionable
